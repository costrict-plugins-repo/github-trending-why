# Changelog

All notable changes to WHY will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-04-11

### Added

- Core WHY skill with three-tier question generation (WHAT, HOW, WHY)
- Multiple-choice format with 4 options per question
- Contextual questions rooted in actual implementations
- Per-answer explanations covering correct and incorrect options
- Session scoring with tier breakdown and visual progress bars
- Four trigger modes: Manual, Auto-quiz, Targeted, Review
- Language and framework agnostic, should work with any stack
- Advanced patterns reference for future question types
- Claude Code plugin packaging with manifest
